# CatatKu

Website pencatatan pribadi untuk mengelola kegiatan dengan bantuan AI. CatatKu adalah aplikasi web responsif berbasis PWA, tanpa login, dengan pendekatan local-first menggunakan IndexedDB dan Cloudflare Workers + D1 untuk pengingat.

## Status

Baseline development (M1). Lihat PRD: `CatatKu_PRD_v2.1.md`.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Teknologi

React, Vite, TypeScript, Tailwind CSS, vite-plugin-pwa, dan IndexedDB.
