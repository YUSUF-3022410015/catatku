# CatatKu

Pengelola kegiatan pribadi berbantuan AI (PRD v2.1). Web responsif PWA, tanpa login, local-first dengan IndexedDB, Cloudflare Workers + D1 untuk pengingat.

## Status
Baseline development (M1). Lihat PRD: `CatatKu_PRD_v2.1.md`.

## Menjalankan secara lokal
```
npm install
npm run dev
```

## Teknologi
React + Vite + TypeScript, Tailwind CSS, vite-plugin-pwa, IndexedDB.
